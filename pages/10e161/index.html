不一样的树形构建方式

# 不一样的树形构建方式

我们都知道，构建树形结构的方式有很多种，以下是几种常见的方式：

  1. 递归方式： 递归是一种常见且强大的方式，特别适用于处理嵌套层次结构。通过递归函数，可以从根节点开始，逐级构建树的节点并设置父子关系。
  2. 哈希映射方式： 使用哈希映射可以在构建过程中快速查找父节点，从而更有效地建立父子关系。

本文我们要讲述的就是哈希映射方式。话不多说，直接开始吧。

# 思想

当使用哈希映射方式构建树形结构时，核心思想是通过使用一个哈希映射（例如 Map）来存储树的节点，以便于快速查找和连接节点之间的父子关系。这种方法适用于处理嵌套数据和层次关系，使构建和操作树形结构更加高效和可维护。

以下是使用哈希映射方式构建树形结构的思想和步骤：

  1. 创建一个空的哈希映射，用于存储树的节点。键通常是节点的唯一标识符，例如节点的值，值是节点本身。
  2. 遍历待构建树的节点列表。
  3. 对于每个节点：
    • 通过节点的标识符（通常是节点的值）在哈希映射中查找父节点，看是否已存在。
    • 如果父节点不存在，创建一个新的父节点，并将其放入哈希映射中。父节点的键可以是节点的 parentValue。
    • 获取当前节点对应的已存在节点（如果存在），用于设置子节点列表。
    • 将当前节点放入哈希映射中，用节点的标识符作为键，节点本身作为值。
    • 将当前节点添加为父节点的子节点之一。
  4. 完成遍历后，哈希映射中存储了构建好的树形结构，节点之间的父子关系得到正确建立。

使用哈希映射方式的优点包括：

  • 快速查找：可以通过节点标识符快速查找父节点，减少了搜索时间。
  • 高效构建：建立父子关系只需要常数时间，不会随着节点数量的增加而变慢。
  • 易于维护：由于节点存储在哈希映射中，可以方便地修改、删除和重新连接节点。

总之，通过使用哈希映射方式，可以以高效、快速和可维护的方式构建复杂的树形结构，适用于处理各种层次关系和嵌套数据。

# 实现

public class TreeNode {
    private String id; // 唯一标识符，通常是节点的值
    private String name; // 节点名称
    private String parentId; // 父节点的标识符
    private List<TreeNode> children; // 子节点列表

    // 构造函数
    public TreeNode(String id, String name, String parentId) {
        this.id = id;
        this.name = name;
        this.parentId = parentId;
        this.children = new ArrayList<>();
    }
    
   public TreeNode(String id,String parentId) {
        this.id = id;
        this.parentId = parentId;
        this.children = new ArrayList<>();
    }

    // 获取节点的唯一标识符
    public String getId() {
        return id;
    }

    // 获取节点的名称
    public String getName() {
        return name;
    }

    // 获取节点的父节点标识符
    public String getParentId() {
        return parentId;
    }

    // 获取节点的子节点列表
    public List<TreeNode> getChildren() {
        return children;
    }

    // 添加子节点
    public void addChild(TreeNode child) {
        children.add(child);
    }

    // 其他属性的访问和操作方法
}

构建树形

import java.util.*;
import java.util.stream.Collectors;

public class TreeExample {

    public static void main(String[] args) {
        List<TreeNode> nodeList = new ArrayList<>();
        nodeList.add(new TreeNode("A", "0"));
        nodeList.add(new TreeNode("B", "A"));
        nodeList.add(new TreeNode("C", "A"));
        nodeList.add(new TreeNode("D", "B"));
        nodeList.add(new TreeNode("E", "C"));
        nodeList.add(new TreeNode("F", "B"));
        nodeList.add(new TreeNode("G", "A"));
        Map<String, TreeNode> treeNodeMap = buildTree(nodeList);
        System.out.println(treeNodeMap);
        List<TreeNode> treeNodes = extractResultList(treeNodeMap);
        System.out.println(treeNodes);
    }

    private static Map<String, TreeNode> buildTree(List<TreeNode> nodeList) {
        // 创建一个空的根节点映射
        Map<String, TreeNode> root = new LinkedHashMap<>();

        // 遍历节点列表，建立父子关系并构建树结构
        for (TreeNode item : nodeList) {
            TreeNode parent = root.get(item.getParentId());

            // 如果父节点不存在，则创建一个新的父节点
            if (Objects.isNull(parent)) {
                parent = new TreeNode();
                root.put(item.getParentId(), parent);
            }

            // 获取当前节点对应的已存在节点
            TreeNode existingNode = root.get(item.getId());

            // 如果已存在节点存在，则将当前节点的子节点列表设置为已存在节点的子节点列表
            if (Objects.nonNull(existingNode)) {
                item.setChildren(existingNode.getChildren());
            }

            // 将当前节点放入树结构映射中
            root.put(item.getId(), item);

            // 将当前节点添加为父节点的子节点
            parent.addChild(item);
        }

        return root;
    }

    private static List<TreeNode> extractResultList(Map<String, TreeNode> tree) {
        // 创建一个空的结果列表
        List<TreeNode> resultList = new ArrayList<>();

        // 获取所有根节点
        List<TreeNode> rootChildren = tree.values().stream()
                .filter(entity -> entity.getParentId() == null)
                .collect(Collectors.toList());

        // 遍历根节点，将其添加到结果列表中
        for (TreeNode entity : rootChildren) {
            if (CollectionUtil.isNotEmpty(entity.getChildren())) {
                resultList.addAll(entity.getChildren());
            }
        }

        return resultList;
    }
}

将逐步构建树形结构：

  1. 首先，创建一个空的根节点映射。
  2. 遍历节点列表，处理每个节点：
    • 节点 A 没有父节点，因此我们将其作为根节点，创建一个新的树形结构，以 A 为键，值为 A 节点。
    • 节点 B 的父节点是 A，我们查找根节点映射中是否已存在 A 节点，已存在则将 B 添加为 A 的子节点。
    • 节点 C 的父节点是 A，同样查找 A 节点并添加 C 为其子节点。
    • 节点 D 的父节点是 B，查找 B 节点并添加 D 为其子节点。
    • 节点 E 的父节点是 C，查找 C 节点并添加 E 为其子节点。
    • 节点 F 的父节点是 B，查找 B 节点并添加 F 为其子节点。
    • 节点 G 的父节点是 A，查找 A 节点并添加 G 为其子节点。
  3. 完成后，我们得到一个树形结构，其中根节点是 A，A 的子节点是 B、C、G，B 的子节点是 D、F，C 的子节点是 E。
